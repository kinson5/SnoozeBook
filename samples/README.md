## 📲 如何在 iPhone / 模拟器上导入测试？

### 方法一：直接从 GitHub Raw 链接在 Safari 中下载导入
在 iPhone Safari 浏览器中打开以下直链，点击下载并保存到「文件 (Files)」App：
- [下载 1_Alice_in_Wonderland_Ch1.mp3](https://raw.githubusercontent.com/kinson5/SnoozeBook/main/samples/1_Alice_in_Wonderland_Ch1.mp3)
- [下载 2_Sherlock_Holmes_Scandal.mp3](https://raw.githubusercontent.com/kinson5/SnoozeBook/main/samples/2_Sherlock_Holmes_Scandal.mp3)
- [下载 3_Lu_Xun_Baicaoyuan.mp3](https://raw.githubusercontent.com/kinson5/SnoozeBook/main/samples/3_Lu_Xun_Baicaoyuan.mp3)

### 方法二：在 SnoozeBook 应用内导入
1. 打开 **SnoozeBook** 应用。
2. 在首页轻触「**导入本地音频文件**」（或右上角书架中的导入按钮）。
3. 在弹出的 iOS 文件选择器中选择下载的 `.mp3` 样本文件。
4. 应用将秒级完成安全沙盒复制、解析封面并进入播放界面。

## 🧪 建议审核员体验的核心特性

1. **盲操手势模式 (Full-Screen Gestures)**：
   - 轻触播放界面的「手势 (Gestures)」紫色按钮，进入超暗全屏手势模式。
   - 单击屏幕任意区域播放/暂停；
   - 左右水平滑动手势：快退 15 秒 / 快进 15 秒；
   - 上下垂直滑动手势：平滑调节系统播放音量。
2. **人声智能放大 (Voice Boost)**：
   - 展开高级音效控制面板，在 `+0dB / +6dB / +12dB` 之间切换，体验低底噪人声穿透增强。
3. **入睡检测与渐隐倒计时 (Smart Sleep)**：
   - 启动定时器（例如 5 分钟），开启智能入睡检测；
   - 倒计时结束前最后一分钟，音量将平滑渐隐至静音，并自动回退一定时长。
